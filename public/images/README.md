# تصویرهای اختیاری

هر تصویری که این‌جا بگذارید، جای نقاشیِ SVG همان صحنه یا شخصیت را می‌گیرد.
اگر فایل نباشد، بازی خودش نسخه‌ی SVG را نشان می‌دهد.

- پس‌زمینه‌ها: `bg/<id>.webp` — نسبت ۱۶:۹، پیشنهاد ۱۹۲۰×۱۰۸۰
  شناسه‌ها: dream, village, forge, forest, pass, lair, gate, hall, tower, sunrise, valley, stars
- شخصیت‌ها: `char/<id>.webp` — پس‌زمینه‌ی شفاف، نسبت ۲:۳ (مثلاً ۸۰۰×۱۲۰۰)
  شناسه‌ها: nilufar, bahram, wanderer, dragon
